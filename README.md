# 📱 PhoneChat — SillyTavern Extension

ส่วนเสริม SillyTavern ที่เพิ่ม UI มือถือสไตล์ iPhone ให้คุณแชท โทร บันทึกโน้ต และอื่นๆ ได้เหมือนมือถือจริง **โดยไม่กระทบแชทหลักของ SillyTavern เลย**

---

## ✨ ฟีเจอร์ Phase 1

### 💬 แอพแชท
- UI สไตล์ iPhone พร้อม Dynamic Island
- ดึงรูปและชื่อตัวละครจาก SillyTavern จริงๆ
- **ปุ่มส่งข้อความ** (ผู้ใช้ส่งเอง) + **ปุ่มให้บอทตอบ**
- แสดง typing indicator เหมือนกำลังพิมพ์จริง
- **Long press** ข้อความบอท → สร้างคำตอบใหม่ (re-roll)
- ส่งได้: ข้อความ, รูปภาพ, สติกเกอร์, โลเคชั่น, โอนเงิน, คลิปเสียง

### 📞 โทรศัพท์
- หน้าจอโทรพร้อมรูปตัวละครเบลอเป็นพื้นหลัง
- ตัวอักษรลอยทีละตัวเหมือนในหนัง
- พิมพ์คุยระหว่างโทรได้
- ปิดเปิดไมค์, วางสาย

### 📝 โน้ต
- ผู้ใช้เขียนโน้ตได้ บอทก็เขียนโน้ตได้
- ถ้าโน้ตเปลี่ยน บอทอาจทักถึงในแชท

### 🎨 ปรับแต่ง
- สีธีม 6 สี
- โหมดสว่าง/มืด
- พื้นหลังแชทได้เอง
- ความเร็วการตอบบอท: ช้า / ปกติ / เร็ว

### 🎭 สติกเกอร์
- สติกเกอร์ในตัว + เพิ่มเองได้ + บันทึกไว้

---

## 🚀 วิธีติดตั้ง

### วิธีที่ 1: ผ่าน URL (แนะนำ)
1. เปิด SillyTavern → **Extensions** (ไอคอนปริศนา 🧩)
2. กด **Install extension**
3. วาง URL ของ GitHub repository นี้
4. กด **Save & Apply**

### วิธีที่ 2: ติดตั้งมือ
1. Clone repo นี้ลงในโฟลเดอร์ `SillyTavern/public/extensions/`
2. Refresh SillyTavern

## ⚠️ หมายเหตุ

- แชทในส่วนเสริมนี้ **ไม่กระทบ** ประวัติแชทหลักของ ST
- ข้อมูลทั้งหมดบันทึกใน `extension_settings` ของ ST
- ต้องเปิด ST และเลือกตัวละครก่อนใช้งาน
- ใช้ Claude API ผ่าน ST endpoint
